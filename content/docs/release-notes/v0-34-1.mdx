# v0.34.1

[View source on GitHub](https://github.com/dorylab/dory/blob/main/release-notes/v0.34.1.md)

## What's Changed

### Improvements
- Centralized SQL safety checks and row limit enforcement into the query execution layer, improving consistency and reliability of SQL query validation across the application.

### Fixes
- Removed unused SQL console compression utilities, eliminating dead code and reducing bundle size.

### Internal
- Refactored SQL-related logic to decouple safety and limits from UI hooks and move them into server-side execution paths, enabling more robust and testable query handling.
